# Astable Multivibrator Circuit Analysis & Implementation

This repository contains the design, hardware setup, and mathematical timing analysis of a BJT-based astable multivibrator circuit implemented using BC337 NPN transistors.

---

### 📌 Project Overview
- **Objective:** Design an oscillator circuit producing a continuous square wave output without external triggering.
- **Transistors Used:** BC337 NPN BJT.
- **Documentation:** Full experimental findings and timing calculations generated via LaTeX.

---

### ⚙️ Technical Highlights
- **Frequency & Duty Cycle:** Theoretical calculations versus hardware measurements for RC time constants ($T = 0.693 \cdot R \cdot C$).
- **Switching Behavior:** Detailed analysis of transistor saturation and cutoff states during oscillation.
- **Waveform Analysis:** Collector and base voltage waveforms documented and analyzed.

---

### 📂 Repository Structure
- `/reports` : Comprehensive LaTeX technical laboratory report.
- `/schematics` : Circuit diagrams and simulation models.
